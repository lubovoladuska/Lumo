# Lumo

Личный голосовой ИИ-ассистент в духе Джарвиса. Просыпается по имени **«Вальтер»**, понимает
русскую речь, думает с помощью LLM (DeepSeek), отвечает естественным голосом и умеет действовать:
ставить таймеры и напоминания, запоминать факты, помнить разговор между устройствами.

Всё, кроме LLM, работает **локально и бесплатно**: распознавание речи, синтез голоса,
слово-активатор, память.

> Статус: MVP на ПК (Windows). Дальше: Android-клиент, управление ПК, музыка, умный дом,
> мессенджеры, свой голос. Разработка идёт по спецификациям [OpenSpec](https://github.com/Fission-AI/OpenSpec), см. `openspec/`.

## Архитектура

```
 ┌──────────── ПК-клиент (lumo-desktop) ────────────┐        ┌──────────── Ядро (lumo-core) ─────────────┐
 │ микрофон → «Вальтер» (Vosk) → запись (Silero VAD)│  текст │ WebSocket API ─► диалоговый движок        │
 │          → речь в текст (faster-whisper, GPU)    │ ─────► │                   │  ▲                    │
 │                                                  │        │       DeepSeek API ◄─┘  │ tool calling      │
 │ динамики ◄─ синтез речи (Silero TTS)             │ ◄───── │                   ▼                       │
 └──────────────────────────────────────────────────┘ ответы │ навыки: время, память, таймеры, …         │
                                                    события │ SQLite: факты, история, таймеры           │
 ┌──── будущие клиенты: Android, веб ────┐ ─────────────────► │ планировщик напоминаний                   │
 └───────────────────────────────────────┘                    └───────────────────────────────────────────┘
```

- **Ядро думает и помнит, клиенты слушают и говорят.** Ядро работает только с текстом, поэтому
  любой клиент (ПК, телефон) подключается одинаково, а память у всех общая.
- **Навыки — плагины.** Новый навык — это модуль в `src/lumo/core/skills/` с декоратором `@skill`.
  Опасные действия (`confirm=True`) выполняются только после голосового «да».

| Компонент | Технология | Где работает |
|---|---|---|
| Слово-активатор | Vosk (small-ru) с грамматикой из одного слова | CPU |
| Подавление эха | WebRTC AEC3 (через livekit) | CPU |
| Конец фразы, перебивание | Silero VAD | CPU |
| Музыка | Яндекс Музыка (yandex-music) + miniaudio | CPU |
| Управление ПК | Get-StartApps, Core Audio (pycaw), WinAPI | CPU |
| Речь → текст | faster-whisper `small`, int8 | GPU (CUDA) или CPU |
| Мозг | DeepSeek `deepseek-chat`, tool calling | облако |
| Текст → речь | Silero TTS v4 (ru) | CPU |
| Память | SQLite | локально |

## Установка (Windows)

Нужны: [uv](https://docs.astral.sh/uv/), ключ [DeepSeek API](https://platform.deepseek.com/),
для GPU — драйвер NVIDIA (CUDA-библиотеки ставятся pip-пакетами автоматически).

```bash
git clone https://github.com/lubovoladuska/Lumo.git
cd Lumo
uv sync --extra core --extra desktop
cp .env.example .env        # впишите LUMO_DEEPSEEK_API_KEY и свой LUMO_TOKEN
uv run lumo-download-models # ~1 ГБ: Vosk, Silero TTS, Whisper
```

uv сам скачает Python 3.12 — системный Python не трогается.

## Запуск

В двух терминалах:

```bash
uv run lumo-core            # ядро
uv run lumo-desktop         # голосовой клиент
uv run lumo-desktop --text  # или текстовый режим без микрофона
```

## Что умеет сейчас

| Скажите | Что произойдёт |
|---|---|
| «Вальтер, который час?» | назовёт время |
| «Вальтер, поставь таймер на 5 минут для пасты» | через 5 минут: «Сработал таймер „паста“» |
| «Вальтер, напомни завтра в 9 позвонить маме» | напомнит, даже если ядро перезапускалось |
| «Вальтер, какие у меня напоминания?» / «отмени таймер для пасты» | список / отмена |
| «Вальтер, запомни, что мой любимый цвет синий» | запомнит навсегда |
| «Вальтер, какой у меня любимый цвет?» | вспомнит |
| «Вальтер, забудь мой любимый цвет» → «да» | удалит после подтверждения |
| любая фраза во время ответа | замолчит и выполнит новую команду (эхо колонок вычитается) |
| «Стоп» во время ответа | просто замолчит |

### Компьютер

| Скажите | Что произойдёт |
|---|---|
| «Вальтер, открой Телеграм» / «закрой браузер» | запустит или закроет приложение (ищет в меню «Пуск») |
| «Вальтер, открой ютуб» / «найди рецепт плова» | откроет сайт / результаты поиска |
| «Вальтер, громкость на 30» / «потише» / «выключи звук» | системная громкость |
| «Вальтер, пауза» / «следующий трек» | управляет музыкой Вальтера или любым плеером |
| «Вальтер, выключи компьютер через час» → «да» | запланирует выключение (и «отмени выключение») |
| «Вальтер, заблокируй компьютер» / «сверни всё» | блокировка экрана / рабочий стол |
| «Вальтер, сделай скриншот» | сохранит в `Изображения/Lumo` |

### Музыка (Яндекс Музыка)

| Скажите | Что произойдёт |
|---|---|
| «Вальтер, включи Кино» / «включи Bohemian Rhapsody» | исполнитель, трек, альбом или плейлист |
| «Вальтер, включи мою волну» / «мои любимые» | «Моя волна» / «Мне нравится» |
| «Вальтер, что играет?» / «лайкни» | название трека / в «Мне нравится» |
| «Вальтер, музыку потише» | громкость музыки отдельно от системной |

Музыка играет внутри Вальтера: пока он говорит или слушает, она приглушается, а позвать
и перебить его можно прямо поверх музыки.

**Как подключить Яндекс Музыку.** Нужна подписка Плюс (без неё API даёт только 30-секундные
отрывки). Токен получите сами и никому его не передавайте:

1. Откройте в браузере
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
   и войдите в свой аккаунт Яндекса.
2. После входа адресная строка будет вида `…#access_token=y0_AgAAAA…&token_type=…` —
   скопируйте значение между `access_token=` и `&`.
3. Впишите его в `.env`: `LUMO_YANDEX_MUSIC_TOKEN=…` и перезапустите `lumo-desktop`.

Работа идёт через неофициальную библиотеку [yandex-music](https://github.com/MarshalX/yandex-music-api),
поэтому при изменениях на стороне Яндекса что-то может временно перестать работать.

## Разработка

```bash
uv sync --extra core --extra dev --extra desktop
uv run pytest     # тесты (голосовые — только при скачанных моделях)
uv run ruff check
```

Структура:

```
src/lumo/
  protocol/   сообщения ядро ↔ клиент
  core/       сервер, движок диалога, навыки, память, планировщик
  desktop/    ПК-клиент: микрофон, wake word, STT, TTS, текстовый режим
openspec/     спецификации и план изменений
tests/
```

## Лицензии моделей

Silero TTS распространяется по лицензии CC BY-NC (некоммерческое использование). Для коммерческого
применения синтез заменяется на Piper через интерфейс `TTSEngine`.
