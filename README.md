# Lumo

Личный голосовой ИИ-ассистент в духе Джарвиса: просыпается по имени («Вальтер»),
понимает речь, отвечает приятным голосом и умеет действовать — управлять ПК,
умным домом и музыкой, ставить таймеры, читать и отправлять сообщения, звонить.

> Статус: проектирование. Разработка ведётся по спецификациям [OpenSpec](https://github.com/Fission-AI/OpenSpec) — см. папку `openspec/`.

## Цели

- **Голос:** wake word → распознавание речи → LLM → синтез речи.
- **Действия:** расширяемая система навыков (tool calling).
- **Везде:** ПК и телефон с общей памятью и историей.
- **Почти бесплатно:** платим только за DeepSeek API, остальное — open source.
