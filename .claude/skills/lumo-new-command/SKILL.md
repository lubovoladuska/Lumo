# Новая команда Вальтера

## 1. Где выполняется?
- Только данные/логика (время, память, таймеры) → навык целиком в ядре, `src/lumo/core/skills/<тема>.py`.
- Трогает ОС, звук, сеть пользователя → навык ядра — тонкий, работа — действие клиента
  `src/lumo/desktop/actions/<тема>.py`. Ядро не импортирует ничего Windows-специфичного.

## 2. Навык ядра
```python
class XParams(BaseModel):
    level: int = Field(ge=0, le=100, description="…по-русски, это читает LLM")

@skill("pc_x", "Что делает — по-русски, с примерами фраз.", XParams,
       reply="silent" | "short" | "normal" | (lambda p: ...),   # см. ниже
       confirm=True, describe=lambda p, ctx: "выключить компьютер")  # только для опасного
async def pc_x(params: XParams, ctx: SkillContext) -> str:
    return await ctx.device("pc.x", params.model_dump())   # или логика ядра
```
- Модуль подхватывается автоматически (кроме `_*.py`). Имя навыка уникально.
- Ошибку для пользователя возвращай строкой, начинающейся с `"Ошибка: "` — так режимы ответа
  поймут, что нужен полный ответ.
- `reply`: `silent` — частые действия без информации (громкость, пауза); `short` — «Готово»
  (открыть, скриншот); `normal` — вопросы и всё, где важен результат. Функция от параметров,
  если зависит (`get` → normal).
- Если LLM путает навыки — уточни description (как сделали для `pc_volume` vs `music_volume`)
  и/или правило в `_PERSONA` (`core/engine.py`).

## 3. Действие клиента
В классе действий (`PcActions`/`MusicActions`) метод + строка в `register()` под префиксом
возможности: `"x": self.x` → действие `pc.x`. Синхронные функции сами уйдут в поток.
Ожидаемая ошибка — `raise ActionError("понятный текст")`. Новая возможность (не pc/music) —
новый префикс, клиент объявит её автоматически.

## 4. Тесты (обязательно)
- Маршрутизация навыка: `tests/test_pc_skills.py` (фикстуры `run`, `pc` — фейковый клиент
  из `tests/test_devices.py::add`).
- Режим ответа: параметризованный `test_default_styles` в `tests/test_reply_styles.py`.
- Логика действия без ОС: подмени Windows-вызовы (пример `FakeVolume` в `test_pc_actions.py`).
- Сценарий с LLM: `ScriptedLLM(tool("pc_x", json.dumps({...})), text("…"))` + `make_engine`.
