# Spec Delta

## ADDED Requirements

### Requirement: Действие только через навык
Система SHALL не отдавать пользователю ответ, который сообщает о выполненном действии («громкость 10 процентов», «включаю», «открыл»), если за реплику не был вызван ни один навык; вместо этого система SHALL один раз попросить языковую модель выполнить действие вызовом навыка и не сохранять выдуманный ответ в истории. Короткие команды без глагола («громкость 10», «тише», «пауза») SHALL считаться командами.

#### Scenario: Короткая команда
- **WHEN** пользователь говорит «громкость 10», а модель отвечает «Громкость системы — 10 процентов», не вызвав навык
- **THEN** система просит модель выполнить действие, громкость действительно меняется на 10%, а выдуманный ответ не попадает в историю

#### Scenario: Обычный разговор
- **WHEN** пользователь говорит «привет», и модель отвечает без навыков
- **THEN** ответ отдаётся сразу, без повторного запроса
