# Design

## Context

Сейчас после вызова навыков движок всегда делает ещё один запрос к LLM, чтобы она сформулировала ответ (см. `conversation-engine`). Навыки объявляются декоратором `@skill`, история диалога хранит вызовы навыков (схема БД v2).

## Goals / Non-Goals

**Goals:** режим ответа у навыка, решение «отвечать ли LLM» на стороне ядра, настройка голосом, тихое подтверждение на клиенте.

**Non-Goals:** настройка текста коротких фраз голосом; режимы для обычного разговора без навыков (там ответ всегда полный).

## Decisions

### 1. Режим — свойство навыка: `@skill(..., reply="silent" | "short" | "normal" | callable)`
Callable получает параметры и возвращает режим: `pc_volume` молчит при `set/up/down/mute`, но отвечает полностью на `get`. По умолчанию `normal` — существующие навыки не меняют поведение.

### 2. Решение принимает ядро после раунда вызовов
После того как LLM вызвала навыки и они выполнились, движок смотрит на все вызовы реплики (`ctx.tool_log`): есть ошибка или `normal` → как раньше, запрос к LLM; иначе ответ без запроса — `short` (случайная фраза из короткого набора) или `silent`. Экономит 2–5 с на частых командах.
- Альтернатива: просить LLM отвечать коротко через промпт — отклонено: всё равно второй запрос и нестабильный результат.

### 3. Настройки пользователя: таблица `preferences(user_id, key, value)` (схема v3)
Ключ `reply:<имя навыка>`. Навык `set_reply_style(skill, style)` принимает имя навыка из списка инструментов (LLM знает их) и `style` ∈ {silent, short, normal, default}; `default` удаляет настройку. Имя проверяется по реестру через `SkillContext.skill_names`.

### 4. Протокол: `Reply.silent: bool`
Тихий ответ содержит текст «Готово.» для истории и логов, но клиент его не произносит, а играет двухтоновый сигнал. В истории сохраняется вместе с вызовами навыков, чтобы LLM видела реальный порядок событий.

### Режимы по умолчанию
- молча: `pc_volume` (кроме `get`), `media_control`, `music_volume` (кроме `get`), `pc_minimize_all`, `pc_lock`;
- коротко: `pc_open_app`, `pc_close_app`, `pc_open_site`, `pc_web_search`, `pc_screenshot`, `music_like`, `remember_fact`, `set_timer`, `pc_cancel_shutdown`, `set_reply_style`;
- полностью: всё остальное (время, «что играет», таймеры и напоминания со временем, выключение, `music_play`).

## Risks / Trade-offs

- [Пользователь не понял, выполнилось ли тихое действие] → звук подтверждения и «✓» в строке клиента; ошибки всегда вслух.
- [LLM вызвала навык с короткой фразой, хотя пользователь задал ещё и вопрос без навыка] → такое редкость; пользователь может переспросить, а режим можно сменить голосом.
