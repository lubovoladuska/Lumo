# Proposal

## Why

Проект Lumo сейчас пустой. Нужен первый работающий вертикальный срез: сказать «Вальтер», задать вопрос голосом и получить умный голосовой ответ, плюс несколько полезных действий. Одновременно надо заложить архитектуру (ядро + клиенты, общая память, система навыков), на которую потом без переделок лягут Android-клиент, мессенджеры, умный дом и музыка.

## What Changes

- Новое **ядро Lumo** (Python-сервис на ПК): ведёт диалог через DeepSeek API с вызовом инструментов, хранит память и историю, исполняет навыки, планирует таймеры. Общается с клиентами только текстом и событиями через локальный API — так любой будущий клиент (Android, веб) подключается одинаково.
- Новый **ПК-клиент**: слушает микрофон, просыпается на «Вальтер», распознаёт речь локально, отправляет текст в ядро и озвучивает ответ локальным русским голосом. Есть текстовый режим (консоль) для отладки без микрофона.
- **Реестр навыков**: каждый навык — отдельный модуль с описанием для LLM, параметрами и флагом «требует подтверждения».
- Навыки MVP: **таймеры и напоминания**, **текущие дата и время**, **«запомни / что ты знаешь про…»** (долговременные факты).
- **Общая память**: история диалогов и факты в SQLite внутри ядра, привязанные к пользователю, а не к устройству.
- Конфигурация через `.env` (ключ DeepSeek, пути к моделям, порог wake word).

Вне рамок: Android-клиент, мессенджеры, звонки, умный дом, музыка, управление ПК, клонирование голоса.

## Capabilities

### New Capabilities
- `conversation-engine`: ведение диалога с LLM — контекст, персона «Вальтер», вызов навыков, обработка ошибок API.
- `skill-system`: регистрация навыков, их описание для LLM, исполнение и подтверждение опасных действий.
- `assistant-memory`: долговременные факты о пользователе и история диалогов, общая для всех устройств.
- `timers-reminders`: таймеры и напоминания, которые переживают перезапуск и доставляются клиентам.
- `core-api`: локальный API ядра, через который клиенты отправляют реплики и получают ответы и события.
- `voice-client`: голосовой цикл на ПК — wake word, распознавание речи, озвучивание ответов, текстовый режим.

## Impact

- Новый код: `core/` (ядро) и `clients/desktop/` (ПК-клиент), общая конфигурация, тесты.
- Новые зависимости (все бесплатные): FastAPI/uvicorn, openai-совместимый SDK для DeepSeek, SQLite (стандартная библиотека), faster-whisper, Vosk (слово-активатор на старте), Silero VAD и Silero TTS (torch), sounddevice.
- Внешний сервис: DeepSeek API (единственная платная часть).
- Модели скачиваются локально в `models/` (не коммитятся). Нужно ~2–3 ГБ на диске и до ~2 ГБ видеопамяти GTX 1660 Ti.
