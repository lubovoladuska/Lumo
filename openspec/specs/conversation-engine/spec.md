# conversation-engine Specification

## Purpose
Ведёт диалог пользователя с ассистентом «Вальтер»: собирает контекст, получает ответ языковой модели, при необходимости вызывает навыки и возвращает короткий ответ, пригодный для озвучивания.

## Requirements

### Requirement: Ответ на реплику пользователя
Система SHALL принимать текстовую реплику пользователя и возвращать текстовый ответ ассистента на русском языке.

#### Scenario: Простой вопрос
- **WHEN** пользователь отправляет реплику «Сколько будет дважды два?»
- **THEN** система возвращает ответ на русском языке, содержащий «4» или «четыре»

### Requirement: Персона ассистента
Система SHALL отвечать от лица ассистента по имени «Вальтер»: вежливо, по делу, кратко (по умолчанию не более 3 предложений), без разметки Markdown, так как ответ будет озвучен.

#### Scenario: Вопрос об имени
- **WHEN** пользователь спрашивает «Как тебя зовут?»
- **THEN** ответ содержит имя «Вальтер»

#### Scenario: Ответ без разметки
- **WHEN** система формирует любой ответ
- **THEN** ответ не содержит символов Markdown-разметки (`*`, `#`, `` ` ``)

### Requirement: Контекст диалога
Система SHALL учитывать предыдущие реплики текущего разговора и известные факты о пользователе при формировании ответа.

#### Scenario: Отсылка к предыдущей реплике
- **WHEN** пользователь сказал «Меня интересует Париж», а затем спросил «Какая там столица страны?»
- **THEN** ответ относится к Франции

### Requirement: Вызов навыков
Система SHALL позволять языковой модели вызывать зарегистрированные навыки, передавать ей результаты и формировать итоговый ответ с их учётом. За одну реплику SHALL выполняться не более 5 последовательных вызовов навыков.

#### Scenario: Вопрос, требующий навыка
- **WHEN** пользователь спрашивает «Который час?»
- **THEN** система вызывает навык текущего времени и отвечает фактическим временем

#### Scenario: Превышение лимита вызовов
- **WHEN** модель запрашивает шестой вызов навыка в рамках одной реплики
- **THEN** система прекращает цепочку и отвечает пользователю, что не смогла завершить действие

### Requirement: Обработка недоступности LLM
Система SHALL при ошибке или таймауте обращения к языковой модели (более 30 секунд) возвращать понятное пользователю сообщение об ошибке вместо падения.

#### Scenario: Нет сети
- **WHEN** API языковой модели недоступно
- **THEN** система отвечает фразой о том, что сейчас нет связи с «мозгом», и продолжает принимать реплики

#### Scenario: Неверный ключ API
- **WHEN** API возвращает ошибку авторизации
- **THEN** система сообщает, что ключ API недействителен, и записывает ошибку в лог без вывода самого ключа
