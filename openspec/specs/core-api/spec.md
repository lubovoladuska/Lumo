# core-api Specification

## Purpose
Единая точка подключения клиентов (ПК сейчас, Android и другие позже) к ядру ассистента: обмен репликами, ответами, запросами подтверждения и событиями в реальном времени.

## Requirements

### Requirement: Подключение клиента
Система SHALL принимать постоянное двунаправленное соединение от клиента. При подключении клиент SHALL передавать идентификатор устройства и токен доступа из конфигурации.

#### Scenario: Успешное подключение
- **WHEN** клиент подключается с верным токеном и идентификатором устройства
- **THEN** соединение принимается, и клиент получает подтверждение подключения

#### Scenario: Неверный токен
- **WHEN** клиент подключается с неверным или пустым токеном
- **THEN** соединение отклоняется без обработки сообщений

### Requirement: Обмен репликами
Система SHALL принимать от клиента сообщение-реплику с текстом и отвечать сообщением-ответом, связанным с репликой по идентификатору.

#### Scenario: Реплика и ответ
- **WHEN** клиент отправляет реплику с идентификатором `abc`
- **THEN** клиент получает ответ с тем же идентификатором `abc` и текстом ассистента

### Requirement: Запрос подтверждения
Система SHALL отправлять клиенту отдельное сообщение-запрос подтверждения, когда навык требует согласия, и принимать ответ пользователя как обычную реплику.

#### Scenario: Подтверждение через клиент
- **WHEN** навык требует подтверждения
- **THEN** клиент получает сообщение типа «запрос подтверждения» с текстом вопроса

### Requirement: Рассылка событий
Система SHALL отправлять события (например, срабатывание таймера) всем подключённым клиентам пользователя без запроса с их стороны.

#### Scenario: Два клиента
- **WHEN** подключены два клиента и срабатывает таймер
- **THEN** оба клиента получают событие срабатывания

### Requirement: Доступ только из доверенной сети
Система SHALL по умолчанию принимать подключения только с локального компьютера; приём подключений из сети SHALL включаться явно в конфигурации.

#### Scenario: Подключение по умолчанию
- **WHEN** ядро запущено с конфигурацией по умолчанию, и клиент подключается с другого устройства в сети
- **THEN** подключение невозможно

### Requirement: Проверка состояния
Система SHALL предоставлять запрос проверки состояния, сообщающий, что ядро работает, и версию ядра.

#### Scenario: Проверка состояния
- **WHEN** выполняется запрос проверки состояния
- **THEN** ответ содержит статус «ok» и версию
